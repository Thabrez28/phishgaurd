Two-Device Evaluation Demonstration Architecture

PhishGuard Live is specifically architected for cross-network verification. Any external internet-connected device (mobile smartphone, remote workstation, or IoT sensor) communicates securely with the cloud deployment without local network constraints.

[ DEVICE 1: Smartphone / Browser ] │ (User navigates to Render Public HTTPS URL) ▼ [ INTERNET / RENDER CLOUD HTTPS ] │ ├─► PhishGuard Live Flask App │ │ │ ├─► Static Threat Engine (0-100 Score) │ ├─► PostgreSQL Persistence │ └─► Security Alert Generation │ [ DEVICE 2: Laptop / CLI Python Agent ] │ (Executes: python phishguard_agent.py "http://target.com") ▼ [ POST /api/scan REST API ] │ └─► LIVE DASHBOARD UPDATES ON BOTH DEVICES INSTANTLY

Step A: Test from Mobile Phone

  1. Open your mobile phone browser (Chrome/Safari).
  2. Navigate to your live Render public HTTPS URL.
  3. Log in as admin and visit the URL Scanner.
  4. Scan a sample URL. Notice how the scan instantly writes to PostgreSQL.

Step B: Test from External Laptop CLI

  1. Open a terminal on any separate computer.
  2. Run the standalone agent script (no credentials needed).
  3. Watch the agent receive the deterministic score report.
  4. Refresh the dashboard on your phone to see the new scan appear!

Executing the Python CLI Security Agent

The agent/phishguard_agent.py script operates autonomously from any Python 3 environment. It reads the target URL via arguments or stdin, contacts the cloud API endpoint, and renders a colored threat assessment report.

1. Configure Cloud Host URL (Bash / PowerShell):
# In Linux / macOS / Git Bash: export PHISHGUARD_API_URL="{{ request.host_url.rstrip('/') }}" # In Windows PowerShell: $env:PHISHGUARD_API_URL="{{ request.host_url.rstrip('/') }}"
2. Execute Threat Scan via Agent:
python agent/phishguard_agent.py "http://paypal.com.verify-billing-update.xyz/login/secure"
3. Direct cURL Alternative from Any Embedded Device:
curl -X POST "{{ request.host_url }}api/scan" \ -H "Content-Type: application/json" \ -d '{"url": "http://suspicious-target.top/verify"}'
