Enterprise API Architecture

PhishGuard Live exposes a zero-trust, deterministic REST API engineered for SIEM connectors, security orchestration automated response (SOAR), and distributed device monitoring agents. All endpoints return RFC 8259 JSON objects.

Static Heuristics (Zero-SSRF) < 50ms Latency 200 req/hour Default Throttle
GET /api/health
Unauthenticated • Health Monitoring

Returns current operational status of the PhishGuard application server and PostgreSQL database connection.

curl -X GET "{{ request.host_url }}api/health"
Sample 200 OK Response:
{ "application": "PhishGuard Live", "database": "connected", "status": "healthy" }
POST /api/scan
Core Defensive Endpoint

Performs comprehensive static URL threat analysis. Generates a deterministic threat score (0-100), extracts structural anomalies, triggers alerts if high-risk, and writes audit telemetry to PostgreSQL.

cURL Execution Example:
curl -X POST "{{ request.host_url }}api/scan" \ -H "Content-Type: application/json" \ -d '{"url": "http://paypal.com.verify-billing-update.xyz/login/secure"}'
Sample 200 OK Response (Phishing Detected):
{ "success": true, "scan_id": 42, "url": "http://paypal.com.verify-billing-update.xyz/login/secure", "normalized_url": "http://paypal.com.verify-billing-update.xyz/login/secure", "threat_score": 85, "verdict": "PHISHING", "risk_level": "CRITICAL", "indicators": [ { "code": "BRAND_SPOOF", "name": "Suspected Brand Impersonation (Paypal)", "severity": "CRITICAL", "weight": 40 }, { "code": "SUSPICIOUS_TLD", "name": "High-Risk TLD (.xyz)", "severity": "MEDIUM", "weight": 15 }, { "code": "SUBDOMAIN_KEYWORDS", "name": "Security Keywords in Subdomain", "severity": "HIGH", "weight": 20 } ], "explanation": "PhishGuard detected 3 severe threat indicators...", "recommendation": "DANGER: Do NOT click this link, submit credentials, or download attachments.", "scanned_at": "2026-10-06T10:45:00.123456" }
GET /api/stats
Threat Intelligence Telemetry

Returns real-time aggregate threat statistics computed directly from PostgreSQL.

curl -X GET "{{ request.host_url }}api/stats"
Sample 200 OK Response:
{ "active_alerts": 3, "detection_rate_pct": 36.4, "phishing_scans": 12, "safe_scans": 35, "success": true, "suspicious_scans": 8, "total_scans": 55 }
GET /api/scans | /api/alerts
Incident Feeds

Stream recent scan logs or active security alert queues for integration into external SIEM tools. Supports optional ?limit=N parameter.

curl -X GET "{{ request.host_url }}api/scans?limit=10" curl -X GET "{{ request.host_url }}api/alerts"
